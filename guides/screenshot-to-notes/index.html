How to turn multiple screenshots into one editable note

Merge screenshots from a lecture, slides, or a web page in reading order. You can check the extracted text against the originals before saving.

Compare the screenshots with the restored note
  1. 1

    Create a note and add screenshots

    Log in, create or open a note, and select Restore note in the toolbar. Drag in, select, or paste JPG, PNG, or BMP screenshots up to 5 MB each.

  2. 2

    Put the screenshots in order and extract the text

    Arrange the thumbnails in reading order. Select Extract and organize, then check spelling, numbers, and line breaks against each original. Edit the extracted text where needed.

  3. 3

    Rebuild the headings and lists, then review the draft

    Once you have checked the extracted text, select Restore note. Review the headings, paragraphs, and lists. Double-check numbers, formulas, and any text that continues across screenshots. You can edit the draft directly.

  4. 4

    Insert the result or export as Markdown

    Select Insert into note to save the result. The originals are available under Attachments. To use the note in another editor, open More note options and choose Export Markdown.

Check blurry screenshots before saving

Capture complete headings and paragraphs, and avoid cutting off sentences at the edge. Compare formulas, two-column text, and partially obscured text with the originals.
